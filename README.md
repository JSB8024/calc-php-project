# Calcolatore Project

## Descrizione
Questo progetto contiene uno script PHP (`calc.php`) che esegue calcoli  semplici.

## Funzionamento
- Ad ogni operazione incrementa il numero di 1.
- Calcola e stampa il risultato di ogni operazione.

## Utilizzo
php calc.php.


## Output Atteso
Lo script stampa i numeri da 1 a 10.
